# 🛠️ Guia de Desenvolvimento - Git Tutor\n\nEste documento fornece instruções detalhadas para configurar o ambiente de desenvolvimento do Git Tutor.\n\n## Pré-Requisitos\n\n- **Node.js**: 18.x ou superior\n- **npm**: 8.x ou superior (incluído com Node.js)\n- **Git**: 2.30 ou superior\n- **Navegador**: Chrome, Edge, ou Brave (com Manifest V3)\n\n### Instalação dos Pré-Requisitos\n\n#### Windows\n\n1. **Node.js**: Baixe em [nodejs.org](https://nodejs.org/)\n2. **Git**: Baixe em [git-scm.com](https://git-scm.com/)\n3. Reinicie o terminal após a instalação\n\n#### macOS\n\n```bash\n# Com Homebrew\nbrew install node git\n\n# Ou com MacPorts\nsudo port install nodejs20\n```\n\n#### Linux\n\n```bash\n# Debian/Ubuntu\nsudo apt-get install nodejs npm git\n\n# Fedora/RHEL\nsudo dnf install nodejs npm git\n```\n\n## Setup Inicial\n\n### 1. Clone o Repositório\n\n```bash\ngit clone https://github.com/ElPadrinho/git-tutor.git\ncd git-tutor\n```\n\n### 2. Instale as Dependências\n\n```bash\nnpm install\n```\n\n### 3. Verifique a Instalação\n\n```bash\nnpm run build\n\n# Deve gerar dist/content.js e dist/popup.js\nls dist/\n```\n\n## Desenvolvimento\n\n### Build em Modo Watch\n\nPara compilação automática ao salvar:\n\n```bash\nnpm run watch\n```\n\n### Recarregar a Extensão no Navegador\n\n1. Abra `chrome://extensions` (ou `edge://extensions`)\n2. Localize \"Git Tutor\"\n3. Clique no ícone de **Reload** (↻)\n4. Teste no [GitHub](https://github.com)\n\n### Scripts Disponíveis\n\n```bash\nnpm run build    # Build único\nnpm run watch    # Build com observação de mudanças\n```\n\n## Estrutura de Pastas\n\n```\ngit-tutor/\n├── .github/                      # Configurações do GitHub\n│   ├── ISSUE_TEMPLATE/           # Templates de issues\n│   └── workflows/                # GitHub Actions CI/CD\n├── src/\n│   ├── content.ts                # Script principal (GitHub)\n│   ├── popup.ts                  # UI do popup\n│   ├── settings.ts               # Gerenciamento de storage\n│   ├── tooltip.ts                # Componente de tooltip\n│   └── data/\n│       └── tutor-content.ts       # Conteúdo educativo\n├── dist/                         # Saída compilada (Git ignored)\n├── manifest.json                 # Manifest V3\n├── popup.html                    # Template do popup\n├── ico.png                       # Ícone da extensão\n├── build.js                      # Script de build customizado\n├── package.json                  # Dependências\n├── tsconfig.json                 # Configuração TypeScript\n├── README.md                     # Documentação\n├── CONTRIBUTING.md               # Guia de contribuição\n├── CODE_OF_CONDUCT.md            # Código de conduta\n├── .editorconfig                 # Configuração de editor\n└── .gitignore                    # Arquivos ignorados\n```\n\n## Convenções de Código\n\n### TypeScript\n\n- Use tipos explícitos\n- Evite `any`\n- Nomes descritivos\n- Indentação: 2 espaços\n\n```typescript\n// ✅ Bom\nfunction getKeyFromTarget(element: HTMLElement): string | undefined {\n  const attr: string | null = element.getAttribute('aria-label');\n  return attr ?? undefined;\n}\n\n// ❌ Ruim\nfunction getKey(e: any): any {\n  return e.getAttribute('aria-label');\n}\n```\n\n### Mensagens de Commit\n\nUse padrão convencional:\n\n```\n<tipo>(<escopo>): <descrição>\n\n<corpo>\n\n<rodapé>\n```\n\n**Tipos**:\n- `feat` - Nova feature\n- `fix` - Correção de bug\n- `docs` - Documentação\n- `style` - Formatação\n- `refactor` - Refatoração\n- `test` - Testes\n- `chore` - Outros\n\n**Exemplos**:\n\n```bash\ngit commit -m \"feat(tooltip): add smooth animations\"\ngit commit -m \"fix(content): fix element detection for new GitHub UI\"\ngit commit -m \"docs: update README with examples\"\n```\n\n### Conteúdo Educativo\n\n- Texto em português claro\n- Termos técnicos em inglês\n- Máx. ~200 caracteres na descrição\n- Máx. ~80 caracteres na dica\n\n```typescript\n// ✅ Bom\nfork: {\n  title: 'Fork',\n  category: 'Repositório',\n  description: 'O botão Fork cria uma cópia do projeto na sua conta, permitindo fazer mudanças sem afetar o original.',\n  tip: 'Use para experimentar sem risco ao projeto principal.'\n}\n```\n\n## Adicionando Novos Elementos\n\n### Passo 1: Detectar o Elemento\n\nEdite `src/content.ts`, função `getKeyFromTarget()`:\n\n```typescript\nif (signal.includes('seu-seletor')) return 'seuElementoKey';\n```\n\n### Passo 2: Adicionar Conteúdo\n\nEdite `src/data/tutor-content.ts`:\n\n```typescript\nseuElementoKey: {\n  title: 'Título',\n  category: 'Categoria',\n  description: 'Descrição...',\n  tip: 'Dica...'\n}\n```\n\n### Passo 3: Traduzir\n\nAdicione em `TRANSLATIONS` para `en` e `es`.\n\n### Passo 4: Testar\n\n```bash\nnpm run build\n# Recarregue em chrome://extensions\n```\n\n## Debugging\n\n### Console.log com Prefixo\n\n```typescript\nconsole.log('[Git Tutor] Seu mensagem aqui');\n```\n\n### DevTools do Navegador\n\n1. Abra qualquer página do GitHub\n2. Pressione **F12** (DevTools)\n3. Vá à aba **Console**\n4. Procure por logs `[Git Tutor]`\n\n### Testar Shadow DOM\n\n```javascript\n// No console\nconst tooltips = document.querySelectorAll('[data-git-tutor]');\ntips.forEach(t => console.log(t.shadowRoot));\n```\n\n## Testes Manuais\n\n### Checklist Completo\n\n- [ ] Elemento é detectado no hover\n- [ ] Tooltip aparece\n- [ ] Tooltip desaparece ao sair\n- [ ] Posicionamento está correto\n- [ ] Toggle enable/disable funciona\n- [ ] Mudança de idioma funciona\n- [ ] Popup mostra status correto\n- [ ] Não há erros no console\n- [ ] Funciona em Chrome e Edge\n\n### Testar Múltiplos Elementos\n\nCrie uma URL de teste:\n\n```\nhttps://github.com/microsoft/vscode\n```\n\nHovere sobre:\n- ⭐ Star\n- 🍴 Fork\n- 👁 Watch\n- Abas (Code, Issues, etc.)\n- Painel About\n\n## Performance\n\n### Checklist\n\n- [ ] Sem memory leaks\n- [ ] Hover responde em <50ms\n- [ ] Tooltip fade-in suave\n- [ ] MutationObserver não trava\n- [ ] Storage não bloqueia UI\n\n### Profiling\n\n```bash\n# Chrome DevTools → Performance → Record\n# Grave hover, mudança de idioma, desativação\n```\n\n## Troubleshooting\n\n### Extensão não aparece em chrome://extensions\n\n```bash\n# Recompile\nnpm run build\n\n# Reinicie o navegador\n# Recarregue chrome://extensions\n```\n\n### Tooltip não aparece\n\n1. Verifique console para erros\n2. Confirme que elemento tem `data-git-tutor-key`\n3. Verifique que `getTutorEntry()` retorna conteúdo\n4. Teste em página sem muitos estilos (ex: github.com)\n\n### Mudança de idioma não funciona\n\n1. Abra DevTools\n2. Vá a Application → Storage → Local Storage\n3. Procure por `gitTutorSettings`\n4. Verifique estrutura JSON: `{enabled: true, language: 'pt'}`\n\n## Publicação\n\nQuando pronto para release:\n\n1. Atualize versão em `package.json`\n2. Crie tag Git: `git tag v0.1.0`\n3. Push: `git push origin v0.1.0`\n4. GitHub Actions fará build automaticamente\n\n## Suporte\n\n- 📖 [README.md](README.md)\n- 🤝 [CONTRIBUTING.md](CONTRIBUTING.md)\n- 💬 [GitHub Discussions](https://github.com/ElPadrinho/git-tutor/discussions)\n- 🐛 [GitHub Issues](https://github.com/ElPadrinho/git-tutor/issues)\n\n---\n\n**Bem-vindo à equipe de desenvolvimento do Git Tutor! 🎉**\n"
